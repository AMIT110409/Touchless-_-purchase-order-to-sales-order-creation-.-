The process follows a straight-through pipeline: a customer sends a Purchase Order (PO) by email → the AI engine extracts and validates the data → Celonis applies business rules → a Sales Order is automatically created in SAP. If anything fails, the PO is routed to the regional Customer Service team for manual handling.

2 What the Application Does

The Touchless Order Creation solution automates the conversion of inbound Purchase Orders (POs) into SAP Sales Orders (SOs), eliminating manual data entry. Specifically, it:

  • Monitors the central sales inbox (salesorders@envalior.com) for incoming PO emails
  • Extracts key data from PDF attachments using AI (customer name, PO number, materials, quantities, dates)
  • Matches the extracted data against SAP Master Data to resolve customer IDs, material codes, and shipping addresses
  • Applies business rules (Sales Organisation, Order Type, SO splitting logic) from an Excel mapping file
  • Sends the validated data to Celonis, which triggers Sales Order creation in SAP EPP
  • Archives the original PO document on the Sales Order in SAP for compliance

3 Prerequisites

The following must be in place before the application can process POs:

  • Azure App Registration — with Mail.ReadWrite and Mail.Send permissions granted by IT for the salesorders mailbox
  • Celonis Connection — active Data Pool with write access for the PO_EXTRACTION_RESULTS table
  • SAP Master Data — Customer (KNA1), Partner Functions (KNVP), and Material Info Records (KNMT) synced to Celonis
  • Excel Mapping File — maintained by the business team with Sales Org, Order Type, Material cross-references, and SO splitting rules
  • SAP Middleware — Webmethods or equivalent configured for PO document archiving (BAPI integration)
